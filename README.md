# 공학용 계산기 (PWA)

`original/calculator.py`(tkinter)를 안드로이드에서도 쓸 수 있도록 웹앱(PWA)으로 옮긴 버전입니다.
설치 없이 브라우저에서 열고, 크롬의 **홈 화면에 추가**로 앱처럼 설치할 수 있으며 오프라인에서도 동작합니다.

## 기능

- **계산기**: 사칙연산, `^`, `sin cos tan asin acos atan sinh cosh tanh sqrt cbrt log ln exp abs`, `π`, `e`
  - 입력 중 실시간 미리보기, 계산 기록, **DEG / RAD** 전환
  - 암묵적 곱셈 (`2pi`, `3x`, `2(3+4)`)
- **방정식 f(x) = g(x)**: 실수 해 자동 탐색, 접하는 중근 처리, 점근선 제외
  - **다항식은 구간 없이 모든 실수 해를 정확히 구합니다.** 식을 계수로 바꾼 뒤 극값으로 구간을 나눠 해를 하나씩 분리하는 방식이에요. (`x^3 - 6x^2 + 11x = 6`, `a*x^2 = 8` 등)
  - 다항식이 아닌 식(`sin(x)`, `1/x` 등)은 구간을 나눠 부호 변화를 찾는 수치해법을 씁니다 (±1000 범위).
  - **그래프 범위는 자동**: 해와 극값이 보이도록 x 범위를, 곡선 값에 맞춰 y 범위를 맞춥니다. 드래그/확대 후에는 **자동 맞춤** 버튼으로 되돌려요.
  - x축(빨강, y=0)과 y축(초록, x=0)을 다른 색으로 구분해 표시합니다.
  - 여러 식을 겹쳐 그리기 (최대 8개)
  - `x`, `y`가 모두 있으면 원·타원·쌍곡선 같은 **암시적 도형**도 그려요 (예: `x^2 + y^2 = 25`)
  - `a*x^2 + b` 처럼 다른 문자는 자동으로 **변수 슬라이더**가 됩니다
- **그래프 조작**: 드래그 이동, 두 손가락 핀치 / 마우스 휠 확대, 탭하면 그 지점의 값 표시
- 다크 모드, 마지막 상태 자동 저장

## AI로 문제 풀기 (Gemini)

**AI 풀이** 탭에 수학 문제를 입력하면 Gemini가 그릴 식을 세우고, 앱이 그래프로 그린 뒤 해를 직접 계산해서 검증합니다. (AI는 식 세우기와 설명, 정확한 계산은 앱이 맡아요.)

- Google AI Studio에서 무료 API 키를 발급해 **AI 설정**에 붙여넣으면 됩니다. 기본 모델은 `gemini-2.5-flash` 입니다.
- **키는 이 기기의 브라우저(localStorage)에만 저장되고, 코드·저장소에는 들어가지 않습니다.** 앱이 Google 서버를 직접 호출해요 (중계 서버 없음).
- 무료 티어는 입력 내용이 Google 제품 개선에 쓰일 수 있으니 개인정보는 넣지 마세요.
- 함수·방정식·원 같은 곡선 문제를 그립니다. 삼각형·점·선분 같은 도형 문제는 아직 풀이 설명만 보여줘요.
- AI 응답은 검증해서, 앱이 해석하지 못하는 식은 제외합니다. AI가 틀릴 수 있으니 "앱이 직접 계산한 결과"와 비교해 보세요.

## 폰에서 쓰기

1. 이 폴더를 웹에 올립니다(예: GitHub Pages). `https://` 주소여야 설치와 오프라인 기능이 켜집니다.
2. 안드로이드 크롬에서 주소를 열고 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**.

## 로컬에서 실행

정적 파일뿐이라 아무 웹 서버로 이 폴더를 열면 됩니다.

```bash
npx serve .
```

## 테스트

수식 엔진 테스트는 Node 또는 브라우저에서 실행합니다.

```bash
node tests/math.test.js
```

Node가 없으면 서버를 띄운 뒤 `/tests/index.html`을 열어 보세요.

## 구조

| 파일 | 역할 |
|---|---|
| `math.js` | 수식 파서(`eval` 미사용), 방정식 풀이 |
| `app.js` | 화면, 그래프 그리기, 터치 제스처 |
| `sw.js`, `manifest.webmanifest` | 오프라인 캐시, 설치 정보 |
| `original/calculator.py` | 원본 tkinter 프로그램 |
